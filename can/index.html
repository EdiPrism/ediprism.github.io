Frequently Asked Engineering Questions

Does CanPrism work in CLion, PyCharm, and RustRover without installing the Java plugin?

Yes. CanPrism depends strictly on com.intellij.modules.platform with zero Java-plugin dependencies, so it installs dynamically and runs identically in CLion, PyCharm, RustRover, IntelliJ IDEA, Rider, DataGrip, GoLand, and WebStorm.

Does CanPrism upload proprietary OEM .dbc or AUTOSAR .arxml files to any external API?

Never. CanPrism runs 100% air-gapped inside your local IDE JVM with zero network sockets, zero cloud APIs, and zero telemetry.
