2. Mandatory HIPAA PHI, PCI-DSS & OEM NDA Safe Bug-Reporting Checklist

Never Attach Live Production PHI, Cardholder PANs, or Proprietary OEM Matrices to Public Issues! Before opening a bug report, always generate a minimal synthetic snippet or scrub your sample locally inside the IDE:
  • In EdiPrism X12 EDIFACT: Press Alt+Shift+X to slice one transaction + run Scrub HIPAA / PII Test Fixture.
  • In EbcdicPrism Copybook Viewer: Press Alt+Shift+R to run Slice & PCI-Scrub Binary Test Fixture.
  • In CanPrism DBC ARXML Viewer: Press Alt+Shift+R to run Export NDA-Scrubbed DBC Test Fixture.
