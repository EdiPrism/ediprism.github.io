How IK3-02 Segment Position Counting Actually Works

IK3-02 is never a file line number. It is a 1-based segment count starting at ST (where ST == 1) inside the transaction matched by AK2-02: 

ISA*...~        (Ignored by IK3-02)
GS*...~         (Ignored by IK3-02)
ST*837*0001*...~  <-- Position 1
BHT*0019*00*...~  <-- Position 2
HL*1**20*1~       <-- Position 3
NM1*85*2*...~     <-- Position 4
HL*2*1*22*0~      <-- Position 5
NM1*IL*1*...~     <-- Position 6
CLM*PAT01*340.50***11:B:1*Y*A*Y*Y~  <-- Position 7 (IK3*CLM*7*2300*8~ / IK4*5:2*... -> 'B')
