Frequently Asked Engineering Questions

Does EbcdicPrism require a COBOL compiler or Java plugin in DataGrip, PyCharm, or Rider?

No. EbcdicPrism depends strictly on com.intellij.modules.platform and uses clean-room Kotlin + standard JDK 21 EBCDIC charsets, so it runs identically in IntelliJ IDEA, DataGrip, PyCharm, Rider, GoLand, and WebStorm.

Does EbcdicPrism transmit copybooks or binary .ebcdic dumps to any external API?

Never. Like EdiPrism X12 EDIFACT, EbcdicPrism runs 100% air-gapped inside your local IDE JVM with zero network sockets, zero cloud APIs, and zero telemetry.
