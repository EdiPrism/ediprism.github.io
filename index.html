Frequently Asked Questions

Does EdiPrism transmit any EDI payloads, schemas, or telemetry over the network?

Never. EdiPrism contains zero HTTP clients, zero cloud/LLM calls, zero analytics SDKs, and zero external telemetry sockets. All parsing, diffing, validation, and HMAC-SHA256 scrubbing execute strictly in-memory inside your local JetBrains IDE process.

Which JetBrains IDEs and versions are supported?

Because EdiPrism is built cleanly against the core IntelliJ Platform API (com.intellij.modules.platform) without Java-only plugin dependencies, a single install works across IntelliJ IDEA, PyCharm, DataGrip, Rider, GoLand, WebStorm, PhpStorm, and RubyMine (2025.1 and newer).

How is licensing handled for corporate and air-gapped teams?

Licensing is handled natively by JetBrains Marketplace (Merchant of Record) with offline RSA certificate verification inside the IDE, supporting individual subscriptions, organization floating/assigned seats, 14-day free trials, and corporate purchase orders.
