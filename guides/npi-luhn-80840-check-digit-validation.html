Why Standard Credit-Card Luhn Fails Without Constant +24

CMS defines the 10-digit NPI as the trailing portion of a 15-digit ISO/IEC 7812 card issuer identifier prefixed by 80840 (80 = Health Applications, 840 = ISO 3166 United States):

// Full 14-digit payload before the 15th check digit:
// Prefix:   8    0    8    4    0   |  9-Digit NPI Base: d1 d2 d3 d4 d5 d6 d7 d8 d9
// Weight:  (1)  (2)  (1)  (2)  (1)  |                    (2)(1)(2)(1)(2)(1)(2)(1)(2)
// Product:  8 +  0 +  8 +  8 +  0  ==  24 (Fixed Healthcare Prefix Constant!)
//
// Check Digit = (10 - ((24 + LuhnSum(d1..d9)) % 10)) % 10

Adding the fixed prefix constant 24 to the standard right-to-left alternating Luhn sum of the first 9 NPI digits produces the exact CMS check digit in O(1) time.
