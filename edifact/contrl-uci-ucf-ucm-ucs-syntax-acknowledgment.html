UN/EDIFACT CONTRL Syntax Acknowledgment & Error Code Lookup

CONTRL is the UN/EDIFACT counterpart to X12 997/999: it acknowledges or rejects an inbound UNB interchange and pinpoints offending segment and element positions via UCS and UCD.

UCI / UCM Action Codes & UCS Error Lookup

Segment & ElementCodeMeaning
UCI-04 / UCM-037 / 87 = This level acknowledged (Accepted); 8 = Interchange received.
UCI-04 / UCM-034Rejected — this level and all lower levels rejected due to syntax errors below.
UCS-01Integer (1-based)1-based segment position starting at UNH == 1 inside the rejected message!
UCS-02 / UCD-0112 / 13 / 16 / 3712 = Invalid value; 13 = Missing mandatory element/segment; 16 = Too many constituents; 37 = Invalid type/character.

Frequently Asked Engineering Questions

How does UCS-01 count segments compared to X12 IK3-02?

They follow the exact same 1-based rule: X12 IK3-02 counts from ST == 1, and UN/EDIFACT UCS-01 counts from UNH == 1.
