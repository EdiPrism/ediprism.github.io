UN/EDIFACT Envelope & UNA Delimiter Architecture

Unlike ASC X12's 106-byte fixed-width ISA header, UN/EDIFACT declares its 6 syntax characters inside an optional 9-byte UNA Service String Advice immediately preceding UNB:

UNA:+.? '
UNB+UNOC:3+5412345000013:14+4012345000094:14+261112:1430+00004819'
  UNH+1+ORDERS:D:96A:UN:EAN008'
    BGM+220+PO-2026-9941+9'
    DTM+137:20261112:102'
    ... [SG2 NAD Parties & SG25 LIN Items] ...
    UNS+S'
    CNT+2:14'
  UNT+38+1'            <-- UNT-01 (38) counts UNH..UNT inclusive; UNT-02 matches UNH-01
UNZ+1+00004819'        <-- UNZ-01 (1) counts messages/groups; UNZ-02 matches UNB-05

Frequently Asked Engineering Questions

Why do naive regex splitters break UN/EDIFACT files?

Because UN/EDIFACT uses ? as an escape character before ', +, and :. For example, O?'Reilly Auto Parts contains an escaped apostrophe inside free text, not a segment terminator. EdiPrism's stateful lexer handles ?? vs ?' cleanly.
