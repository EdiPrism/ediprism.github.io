2. Deterministic HmacSHA256 HIPAA Safe Harbor Test-Fixture Scrubbing

When engineers copy production rejections into Git repositories for JUnit, pytest, or xUnit regression tests, manual find-and-replace frequently misses secondary identifiers or breaks check-digit validation. EdiPrism's offline scrubber applies deterministic, session-keyed HmacSHA256 pseudonymization across:

  • Entity Names & Contacts (NM1, N1, PER): Replaces patient, subscriber, and contact names plus phone/email qualifiers while preserving exact element lengths where required.
  • Geographic Subdivisions & Dates (N3, N4, DMG): Anonymizes street addresses, postal codes, and birthdates while keeping valid calendar CCYYMMDD syntax so companion-guide regexes still pass.
  • Check-Digit & Cross-File Referential Integrity (NM1-09, REF, CLM-01): Generates synthetic 10-digit NPIs satisfying the healthcare 80840 Luhn Mod-10 check digit, and maps identical input IDs to identical synthetic outputs across paired 837 + 835 + 999 files.
